# 💻 BlueOS Mobile PC Simulator v3.0

An interactive, visual desktop PC operating system simulator built entirely in Python using `tkinter`. This project was completely developed and compiled on an Android mobile device using Pydroid 3!

## 🚀 Core Features
* 📱 **Auto-Scaling GUI:** Windows expand to full-screen by default to perfectly fit vertical mobile phone layouts.
* 🛍️ **Blue Store Market:** Buy and deploy app modules using an in-game virtual credit economy.
* 🌐 **Integrated Browser Engine:** Search the web or unlock the hidden `devmenu.com` layout page.
* ⚙️ **Advanced Bootloader Utility:** Allows developers to flash custom UI overlays (Linux Core Terminal or Apple iOS themes).
* 📦 **BPK Package Kit Installer:** Native system utility to deploy standalone custom binary extensions like `flappy_bird.bpk` and `antivirus_pro.bpk`.

## 🛠️ Installation & Deployment
1. Download **Pydroid 3** from the Google Play Store on your Android device.
2. Clone this repository or copy the source code blocks.
3. Paste all 3 parts sequentially into your workspace editor.
4. Press the **Play** button to boot BlueOS!
